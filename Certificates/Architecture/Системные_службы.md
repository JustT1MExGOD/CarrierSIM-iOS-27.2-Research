# Системные службы iOS — свидетельство launchd-определений

Обезличенные извлечения из `launchd`-определений служб, прочитанные напрямую из файловой
системы сборки iOS 27.2 Beta 3 (`24B5099f`). Приведены только поля, относящиеся к
идентификации службы, учётной записи и объявленным MachServices. Полные plist-файлы не
публикуются (они входят в `.gitignore`); сами поля — системные определения без персональных
данных.

## Примечание

Эти определения подтверждают учётные записи и объявленные MachServices. Они **не**
подтверждают пригодность службы для произвольной записи в
`/var/mobile/Library/Carrier Bundles/iPhone`: объявленный MachService — это не то же
самое, что общий API записи файлов.
