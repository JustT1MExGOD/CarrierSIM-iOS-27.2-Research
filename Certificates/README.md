# Публикуемые свидетельства

- `Фрагменты_дизассемблирования.md`: краткие адресные фрагменты с пояснениями.
- `События_диагностики.md`: обезличенные сообщения из одного диагностического запуска.
- `Сравнение_строк.md`: проверенные различия текстовых маркеров.

Полные машинные файлы, оригинальные логи и двоичные данные не публикуются. Фрагменты нельзя использовать как замену исходным Mach-O при независимом разрешении импортов.
