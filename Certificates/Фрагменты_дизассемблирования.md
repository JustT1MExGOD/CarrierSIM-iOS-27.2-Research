# Фрагменты дизассемблирования

Источник: сохранённые офлайн-выдержки исследуемого участка AirTraffic Beta 3 (`24B5099f`). Адреса виртуальные; имена функций **предположительные**.

## Предполагаемая операция переименования

```asm
0x254c9e4d4: mov x0, x24
0x254c9e4d8: mov x1, x27
0x254c9e4dc: mov x2, x24
0x254c9e4e0: mov w4, #0x20
0x254c9e4e4: bl #0x2580c24c0
0x254c9e4e8: cbz w0, #0x254c9e7a4
0x254c9e4ec: bl #0x2580804d0
0x254c9e4f0: ldr w8, [x0]
```

`x24` передаётся в качестве обоих предполагаемых directory FD; после неуспеха выполняется вызов, соответствующий получению адреса `errno`. Точное имя вызываемой функции из имеющегося фрагмента **не разрешено**.

## Другие адреса

| Адрес | Значение по анализу |
|---|---|
| `0x254c9e284` | Предполагаемое открытие каталога с флагами `0x40100000` |
| `0x254c9e3e4` | Предполагаемое создание каталога относительно `x24` |
| `0x254c9e524` | Предполагаемое удаление записи относительно `x24` |
| `0x254c9e558` | Предполагаемый повторный вызов переименования |

Это сокращённые фрагменты исходного отчёта, а не полноценный дизассемблированный бинарник.
