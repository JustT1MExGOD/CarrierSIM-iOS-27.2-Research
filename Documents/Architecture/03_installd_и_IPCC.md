# installd, IPCC и streaming_zip_conduit — официальная установка пакетов

## installd — официальный установщик

`com.apple.mobile.installd` запускается из `/usr/libexec/installd` под учётной записью
`_installd`, MachService `com.apple.mobile.installd`. **Высокая** (launchd-определение).

Это **официальный путь установки** подписанных пакетов: приложений, профилей и IPCC
(carrier-bundle settings). В бинарнике `installd` разобрана таблица chained fixups — 536
реальных импортов, среди которых `___error`, `_mkdir`, `_open`, `_rename`, `_renamex_np`,
`_unlink`, `_realpath`, `_copyfile`, `_lstat`, `_fcntl` — обычные POSIX-вызовы без
`*at`-вариантов. **Высокая** (таблица импортов, а не предположение).

## Что делает IPCC

`.ipcc` — подписанный пакет операторских настроек, который `installd` применяет к системе:
обновляет APN, IMS/VoLTE/VoWiFi, переопределения. Это тот самый «триггер», который
CarrierSIM использует через `install_trigger` для повторного сканирования. **Высокая.**

## streaming_zip_conduit — канал загрузки

`com.apple.streaming_zip_conduit` (258-байтное launchd-определение) — канал потоковой
загрузки ZIP, под учётной записью `mobile`, MachService
`com.apple.streaming_zip_conduit`. Через него хост передаёт ZIP, который затем
распаковывается/применяется — тот же путь, что использует CarrierSIM для отправки
стадийного архива и триггера. **Высокая.**

## Граница штатного пути

IPCC-установка обновляет **операторские настройки** — применимые поля бандла, которые
система разрешает изменить. Она **не даёт** произвольно записывать новые имена бандлов,
симлинки или чужие операторские профили в живой каталог `/var/mobile/Library/Carrier
Bundles/iPhone` — то есть не воспроизводит специфическую операцию Airlift. **Высокая** для
факта существования; **средняя** для полного перечня допустимых изменений IPCC.
