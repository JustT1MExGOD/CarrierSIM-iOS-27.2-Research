# Штатные (документированные) механизмы операторских настроек

Различие, которое нельзя терять: **управление сотовыми настройками** — не то же самое, что
**произвольная запись в каталог carrier bundles**. Ниже — что реально доступно по
документированным каналам и чего они не умеют.

| Канал | Что делает | Пишет ли в `/var/mobile/Library/Carrier Bundles/iPhone`? | Уверенность |
|---|---|---|---|
| Установка `.ipcc` через `installd`/`streaming_zip_conduit` | Применяет подписанный пакет операторских настроек — официальный путь обновления APN/IMS/VoLTE. | Косвенно — обновляет **применимые** настройки, а не даёт инъекцию произвольных имён бандлов/симлинков. | Высокая |
| OTA-обновление операторских настроек (CommCenter) | Загружает и применяет дельту настроек с серверов Apple. | Нет — закрытый канал под CommCenter. | Высокая |
| `CellularPlanDaemon` / eSIM API | Управление тарифными планами eSIM. | Нет — управляет профилями eSIM, не файловым каталогом. | Высокая |
| MDM-профили (DeviceManagement) | Подписанные `.mobileconfig` (APN, ограничения, политики). | Ограничено — задаёт политики, не редактирует сам каталог; требует зачисления устройства. | Средняя |
| Настройки в UI | Пользовательские переключатели оператора/линии. | Нет. | Высокая |

## Чего нет в официальных каналах

- API для записи симлинков или произвольных пакетов в `/var/mobile/Library/Carrier
  Bundles/iPhone` под выбранным именем оператора/IMSI. **Высокая** — это именно та
  специфическая операция, которую закрыл патч, и для которой нет документированной замены.
- Отличие: штатная установка **обновляет настройки**, а Airlift **менял структуру каталога**
  — добавлял чужой профиль под существующим IMSI.

## Граница «документировано vs внутреннее»

- **Документировано:** IPCC через `installd`, OTA-настройки через `CommCenter`, eSIM через
  `CellularPlan`, MDM-профили, UI.
- **Внутреннее (не публичное API):** медиа-синхронизация `atc`/`AirTraffic`, использованная
  Airlift; приватные XPC `CommCenter`; сам sandbox-контур. Использование этих механизмов —
  работа с приватной машинерией, а не с поддерживаемой возможностью.
