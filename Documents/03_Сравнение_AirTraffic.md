# Статическое сравнение AirTraffic

В Beta 2 в исследованном участке встречается строка `Cannot move asset outside of AFC root`. В Beta 3 обнаружены сообщения `Could not open AFC root`, `Could not create directory ... beneath AFC root` и `Failed to move completed file ... beneath AFC root`.

Сопоставление `__text` показало размер `0x18bf0` для Beta 2 и `0x18d68` для Beta 3, разница `0x178` байт. Это размер исследованной секции, а не размер всей библиотеки.

## Адреса в Beta 3

| Адрес вызова | Наблюдаемая форма аргументов | Предполагаемая функция |
|---|---|---|
| `0x254c9e284` | путь, флаги `0x40100000`; возвращённый дескриптор сохраняется в `x24` | `open` |
| `0x254c9e3e4` | `x24`, путь, режим `0755` | `mkdirat` |
| `0x254c9e4e4` | два `x24`, два пути, флаг `0x20` | `renameatx_np` |
| `0x254c9e524` | `x24`, путь, нулевой флаг | `unlinkat` |
| `0x254c9e558` | повторная форма вызова с пятью аргументами | `renameatx_np` |

**Ограничение:** адреса назначения вызовов находятся за пределами доступного фрагмента `__text`; нужная информация о привязке импортов отсутствует. Названия функций остаются предположительными. Само число аргументов не является доказательством конкретного имени.

В Beta 2 виден вызов Objective-C/Foundation с булевым результатом. Точный селектор `moveItemAtPath:toPath:` по имеющимся секциям не подтверждён.

## Проверка строк

Сравнение строк в исходных 128-КиБ фрагментах: `beneath AFC root` — Beta 2: 0, Beta 3: 3; `Cannot move asset outside of AFC root` — Beta 2: 1, Beta 3: 0; `%{errno}d` — Beta 2: 0, Beta 3: 4.
