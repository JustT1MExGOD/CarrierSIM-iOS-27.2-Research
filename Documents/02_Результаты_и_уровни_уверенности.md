# Результаты и уровни уверенности

| Утверждение | Оценка | Основание |
|---|---|---|
| Первая операция внутри Media успешна | Высокая | Диагностический журнал |
| Вторая операция завершилась ошибкой 107 | Высокая | Сообщение AirTraffic в журнале устройства |
| Финальный объект не отправлялся | Высокая | Завершение журнала управляющего процесса на отметке `before-final-asset` |
| В Beta 3 изменён код перемещения | Высокая | Изменение строк и структуры исследованного участка |
| Используется общий дескриптор каталога | Высокая для исследованного фрагмента | Передача регистра `x24` между вызовами |
| Вызов является именно `renameatx_np` | Средняя | Сигнатура из пяти аргументов; таблица импортов отсутствует |
| `0x40000000` означает `O_EXECONLY` | Низкая/средняя | Гипотеза из отчёта, заголовок конкретной сборки отсутствует |
| `107` имеет символическое имя `ENOTCAPABLE` | Средняя | Текст ошибки подтверждён, имя константы для этой сборки не сверено с заголовком |
| Причина отказа — конкретная проверка sandbox | Не установлено | Не найден участок ядра, принимающий решение |
| `fileproviderd` выполнял перемещение | Не подтверждено | Сообщение относится к другому процессу и операции чтения |
| Возврат функциональности возможен только через KRW | Не доказано | Отказ одного метода не доказывает невозможность всех иных |

**Важно:** метки «высокая» и «средняя» характеризуют качество доступных свидетельств, а не гарантию корректности всей интерпретации.
