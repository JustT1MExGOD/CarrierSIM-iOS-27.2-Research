# Открытые вопросы

1. Получить полные данные привязки импортов AirTraffic Beta 3 и разрешить адреса вызовов до реальных символов.
2. Проверить определение `0x40000000` в заголовках, соответствующих исследуемой сборке.
3. Проверить `0x20` в контексте фактического импортируемого вызова.
4. Установить символическое имя ошибки 107 по надёжному заголовку и объяснить расхождение с индексами извлечённой таблицы строк.
5. Установить точный компонент, отклоняющий путь за AFC root; обычный directory FD недостаточен для такого вывода.
6. Проверить полный бинарник AirTraffic из RC: наблюдаемое поведение RC известно, но идентичность его кода Beta 3 не доказана.
7. Независимо оценить роль параллельных событий `fileproviderd`.

Отказ старого метода на RC **не доказывает** необходимости KRW, существования другого уязвимого демона или невозможности любых альтернативных штатных механизмов.
