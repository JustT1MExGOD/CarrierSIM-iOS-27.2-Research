# Флаги и ошибка 107

В предполагаемом вызове открытия каталога передаётся `0x40100000`. Отдельный бит `0x00100000` в анализе отнесён к `O_DIRECTORY`. Для `0x40000000` предложена интерпретация `O_EXECONLY`, но она **не подтверждена заголовком SDK исследуемой версии**. Нельзя считать этот бит доказательством специальной «тюрьмы» для путей.

При предполагаемом переименовании передаётся `0x20`; в исходном анализе он сопоставлен с `RENAME_NOFOLLOW`. Именованная константа требует отдельной проверки по подходящему заголовку и сигнатуре импортируемого вызова. Классический `O_NOFOLLOW` не обнаружен в указанном значении флагов открытия.

**Обычный файловый дескриптор каталога не блокирует переход через `..` сам по себе.** Конкретная политика ограничения разрешения путей на уровне ядра по опубликованным данным не установлена.

Журнал устройства содержит `[107: Capabilities insufficient]`. Это достоверная пара «число + текст» из конкретного события. Соответствие символическому имени `ENOTCAPABLE` остаётся вероятной, но не независимо подтверждённой интерпретацией. В исходном анализе также отмечено несовпадение индексов в извлечённой таблице текстов ошибок ядра; оно не устранено прямой проверкой нужного заголовка.
